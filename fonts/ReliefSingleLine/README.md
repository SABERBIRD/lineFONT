# Relief SingleLine SVG

An open-path display and technical lettering font by the Relief SingleLine
Project Authors. This family packages the regular SVG face as a .lint font.
The converter omits kerning, alternate or unmapped glyphs, multi-character
glyphs and the incomplete mathematics-technical block.

The font and its converted form use the SIL Open Font License 1.1.
See [source.json](source.json) for the revision and conversion changes.
