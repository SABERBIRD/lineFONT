# Norm Stroke

A single-line technical lettering font for Latin and Greek. This conversion
uses the original SVG 1.1 font by octycs, based on the public-domain
ISO 3098 drawing by Wikimedia Commons user K7.

The .lint preserves the source font's metrics and pen moves. Arcs were converted
to cubic Béziers. The punctuation, quotes and mathematics-technical blocks
were omitted because the upstream font supplies only part of each block.
Pair it with a fallback font for those characters.
