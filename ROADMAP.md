# План розвитку lineFONT

Пункти виконуються у наведеному порядку. Релізи створюються лише за запитом користувача.
Зміни схеми .lint потребують рішення щодо версії формату.

1. [x] **Екранний розмір зразка.** Висота великих літер 12–96 CSS px, перенос під доступну ширину.
2. [x] **Список відсутніх символів.** Оригінальні кластери та Unicode-коди з можливістю копіювання.
3. [x] **Збереження SVG зразка.** Поточна фраза, розмір і переноси відтворюються у файлі.
4. [x] **Локальний файл .lint у HTML.** Валідація ядром, оновлення метрик, фрази та карток, відновлення після помилки.
5. [x] **Пошук гліфів.** Усі сторінки, пошук за символом і Unicode-кодом без повторної генерації HTML.
6. [x] **Докладна картка гліфа.** Перемикачі траєкторій, напрямів, контрольних точок, advance та anchors.
7. [x] **Порівняння двох шрифтів.** Одна фраза, висота та параметри розкладки.
8. [ ] **Мобільна доступність — частково виконано.** Збільшені цілі дотику, видимий фокус, клавіатурне відкриття карток, локальне прокручування та повідомлення при блокуванні скриптів реалізовані. Перевірено Chromium із сенсорним введенням при ширині 320 px. Залишилися фізичні Android та iOS, системний вибір файлу, масштабування жестом, копіювання й завантаження SVG на цих пристроях.
9. [ ] **Локалізації перегляду.** Узгоджені українські й англійські підписи, помилки та доступні назви.
10. [ ] **Якість мовних зразків.** Перевірка носіями, технічна фраза й окремий набір повноти абетки.
11. [ ] **API точних меж штрихів.** Екстремуми кривих у Rust, спільні приклади для прив’язок, перегляду та експорту.
12. [ ] **JSON Schema.** Структурна схема та визначена межа геометричної валідації.
13. [ ] **Структуровані діагностики.** Код помилки, шлях поля, Unicode гліфа та позиція команди.
14. [ ] **Звіт покриття мов.** Абетки та комбіновані знаки, прямі гліфи, композиції й відсутні символи.
15. [ ] **Корпус діакритики.** NFC/NFD, кілька знаків, великі й малі літери, ненульовий baseline.
16. [ ] **Політика Unicode.** Версія даних, порядок оновлення та поведінка непідтримуваних кластерів.
17. [ ] **Відтворювана розкладка.** Спільний корпус Rust, JS/WASM і C із допустимою числовою похибкою.
18. [ ] **Ліміти та fuzzing.** Пошкоджені файли, композиції, кількість команд, час і пам’ять.
19. [ ] **Вимірювання швидкодії.** Великі тексти й колекції, реєстрація шрифтів, пошук і розкладка.
20. [ ] **Сумісність версій.** Зміни геометрії, метрик, невідомих полів і відтворення документів.
21. [ ] **Шаблон нового шрифту.** Метадані, п’ять цілісних блоків, вільні символи, ліцензія та мінімальний приклад.
22. [ ] **Імпорт SVG.** Трансформації, одиниці, перетворення у M/L/C та повідомлення про втрати.
23. [ ] **Порівняння версій.** Зміни гліфів, advance та anchors із візуальним накладанням.
24. [ ] **CI внесків шрифтів.** Валідація, повнота блоків, ліцензія та артефакти рев’ю.
25. [ ] **Посібник автора.** Наскрізний приклад SVG → .lint → композиція → PR.
26. [ ] **Інтеграція bagLING.** Закріплена версія, збереження шрифтів, спільна геометрія екрана й експорту.
27. [ ] **Прив’язки C та Python.** Приклади установки на підтримуваних платформах і узгоджені помилки.
28. [ ] **Фізичні перевірки.** Плотер і гравер, малі розміри, відкриті штрихи, піднімання інструмента й діакритика.
29. [ ] **Оптимізація маршруту.** Довжина холостого ходу, контроль результату й збереження канонічного порядку.
30. [ ] **MCP-адаптер.** Після стабілізації API інструментів надати валідацію, покриття, порівняння та зразки з лімітами ресурсів.
