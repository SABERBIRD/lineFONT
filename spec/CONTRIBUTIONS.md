# Contributions to linefont/1

The [contribution guide](../CONTRIBUTING.md) covers submitting fonts, proposing changes to the specification and contributing implementation code. Format requirements for every producer and consumer are in [FORMAT.md](FORMAT.md).

## Language samples

Review the technical phrase (`text`) and the set of uppercase and lowercase
letters with diacritics (`alphabet`) separately in
`tools/preview-language-samples.json`. The character set is intended for
practical technical text. State the language, regional variant and reviewed
fields in the pull request. Once a native speaker has reviewed both fields,
change `review` from `pending` to `reviewed` and link to the review.
