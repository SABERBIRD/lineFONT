# Contributions to linefont/1

The [contribution guide](../CONTRIBUTING.md) covers submitting fonts, proposing changes to the specification and contributing implementation code. Format requirements for every producer and consumer are in [FORMAT.md](FORMAT.md).

## Мовні зразки

У `tools/preview-language-samples.json` перевірте технічну фразу (`text`) і
набір великих та малих літер з діакритикою (`alphabet`) окремо. Це практичний
набір для технічного тексту. Вкажіть у PR мову, регіональний варіант і які
поля перевірено. Після перевірки обох полів носієм змініть `review` з
`pending` на `reviewed` та додайте посилання на рецензію.
